# AI Nexus brand and showcase assets

[Back to README](../../README.md)

The connected **N** is drawn from simple project-specific paths and three nodes. It suggests several perspectives crossing within one conversation. Warm cream, muted plum, dusty rose, lavender, and stone gray carry the project's existing calm desktop-software tone. The mark is not a provider logo, a font file, or a stock image.

## Files

- `mark.svg`: standalone connected N.
- `hero-light.svg` and `hero-dark.svg`: matching README opening images selected with GitHub's supported `prefers-color-scheme` `<picture>` pattern. Both use system-font fallbacks; no font file is bundled.
- `social-preview.svg`: editable source for `social-preview.png`. The PNG is 1280 × 640 and must stay below GitHub's 1 MB upload limit. To make it the repository's actual social card, a maintainer must upload the PNG in **Settings → General → Social preview**; committing the PNG alone does not change the GitHub setting.
- `collaboration-flow.svg`: an explanatory diagram, not a product screenshot.
- `../screenshots/chat-demo.png` and `../screenshots/member-status-demo.png`: browser renders of the **actual v0.1.0 web UI** from an isolated copy. Sessions contain deliberately fictional test lines and every model is explicitly offline. No real provider request was sent. The member panel was opened in that isolated copy for the second capture. These images do not demonstrate a live AI reply.
- `../screenshots/first-run.jpg`: older, narrow capture retained for provenance; it is no longer the main README image.

The SVGs were created for this release branch with AI assistance and reviewed as project artwork. They use no copied logo, externally hosted image, or embedded typeface. This records provenance, not a legal guarantee of exclusive authorship. See [source and license inventory](../../SOURCES_AND_LICENSES.md).
